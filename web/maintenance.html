MTBF & LTTR — selected equipment

MTBF (mean time between failures) = operating hours ÷ failure count. LTTR (lost time to repair) = downtime hours ÷ failure count. Failures are breakdown incidents with machine downtime in the selected period (daily downtime logs, breakdown total when reported in range, or linked breakdown work order hours). Operating hours come from daily input run hours. Expand the incident table below to reconcile against work orders.

Choose dates and equipment, then load.

KPI per asset — weekly usage

Uses the same rules as the main dashboard: availability = available ÷ planned (available = scheduled − downtime, capped per day), utilization = run ÷ planned (scheduled hours total, same denominator as availability). Tables are sorted by utilization (highest first) so you can see which equipment performed best. Equipment type is the asset category field.
