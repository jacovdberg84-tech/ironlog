IronLog API

Read-only access for other systems: ERP, Power BI, client portals. Keys are created by an IronLog administrator under Admin → API keys.

How to connect

  1. Ask an IronLog administrator for a key. It starts with ilk_ and is shown only once.
  2. Send it with every request: Authorization: Bearer ilk_… (or the header X-API-Key: ilk_…).
  3. Choose the site with X-Site-Code: main. A key limited to some sites uses its first site when none is given.
  4. Every answer is JSON. Money is US dollars, dates are YYYY-MM-DD, hours are machine hours.

      
Limits and errors

      
    
        
  • Keys only read (GET). They can never change records or reach settings, users or admin screens.
    • 
        
  • 300 requests a minute per key.
    • 
        
  • 401: no key, or the key is unknown, cancelled or past its end date. 403: the key may not read this address, this site, or the licence does not include API access. 429: too many requests this minute.
